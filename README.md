# Warehouse Management System
 
 Веб-програма для роботи з товаром на складі.
 
📊 **[Презентація системи (Warehouse System.pptx)](./Warehouse-System.pptx)** — покрокова інструкція для User та Admin
## Можливості
 
### 🔐 Два рівні доступу:
- **User** - звичайні користувачі, можуть сортувати та додавати картони
- **Admin** - повний контроль: створення Lider, видалення користувачів, перегляд активності
### 📦 SORT:
- **Single** - з вказанням загальної кількості картонів
- **Mix** - без обмеження кількості
- **Vevor** - з вказанням загальної кількості картонів
### 📊 Функції:
- Введення 4-ог остатніх цифр ICC кода та автоматична перевірка
- Управління палетами (відкриття/закриття)
- Лічильники картонів та палет
- Журнал активності
- Статистика по користувачам
## Встановлення в Termux
 
### 1. Встановіть Python та залежності:
```bash
pkg update
pkg install python
```
 
### 2. Встановіть Flask:
```bash
pip install -r requirements.txt
```
 
### 3. Запустіть сервер:
```bash
python app.py
```
 
Сервер запуститься на `http://0.0.0.0:5000`
 
## Встановлення на Windows
 
### 1. Встановіть Python:
Завантажте Python з [python.org](https://www.python.org/downloads/) (версія 3.9 або новіша).
 
⚠️ Під час встановлення обов'язково поставте галочку **"Add Python to PATH"** на першому екрані інсталятора.
 
Перевірте встановлення, відкривши **PowerShell** або **Командний рядок (cmd)**:
```cmd
python --version
```
 
### 2. Перейдіть у папку проекту:
```cmd
cd шлях\до\папки\warehouse-system
```
 
### 3. (Рекомендовано) Створіть віртуальне середовище:
```cmd
python -m venv venv
venv\Scripts\activate
```
 
Після активації у рядку зʼявиться `(venv)` перед шляхом.
 
### 4. Встановіть залежності:
```cmd
pip install -r requirements.txt
```
 
### 5. Запустіть сервер:
```cmd
python app.py
```
 
Сервер запуститься на `http://0.0.0.0:5000`
 
### Доступ з того ж комп'ютера:
Відкрийте браузер: `http://localhost:5000`
 
### Доступ з іншого пристрою в локальній мережі:
1. Дізнайтесь IP-адресу комп'ютера:
```cmd
ipconfig
```
Знайдіть рядок **IPv4 Address** (наприклад, `192.168.1.50`).
 
2. Якщо не з'єднується — дозвольте порт 5000 у брандмауері Windows:
```cmd
netsh advfirewall firewall add rule name="Warehouse App" dir=in action=allow protocol=TCP localport=5000
```
(Команду потрібно виконати від імені адміністратора.)
 
3. На іншому пристрої в тій самій мережі: `http://[IP-адреса]:5000`
   Наприклад: `http://192.168.1.50:5000`
### Наступні запуски:
Кожного разу, коли повертаєтесь до проекту, достатньо:
```cmd
cd шлях\до\папки\warehouse-system
venv\Scripts\activate
python app.py
```

## Як працювати
 
### Для User:
 
1. **Натисніть SORT** на головній сторінці
2. **Виберіть тип:** Single / Mix / Vevor
3. **Введіть ICC код**
   - Якщо код новий: введіть загальну кількість картонів (крім Mix)
   - Якщо код існує: продовжуйте додавати картони
4. **Введіть дані:**
   - Скільки картонів є зараз
   - Номер палети (при першому додаванні)
5. **Закрийте палету** коли вона заповнена
6. **Відслідковуйте прогрес:**
   - Лічильник картонів
   - Прогрес-бар
   - Зелена галочка ✓ при завершенні
### Для Admin:
 
Повний контроль:
- **Користувачі** - список всіх користувачів, можливість видалення
- **Активність** - журнал всіх дій в системі
- **Створити Admin** - додавання нових Admin акаунтів

## База даних
 
Система використовує SQLite з 4 таблицями:
- **users** - користувачі та ролі
- **icc_codes** - ICC коди та прогрес
- **pallets** - палети та їх вміст
- **activity_log** - журнал дій
База даних створюється автоматично при першому запуску.
 
## Безпека
 
- Паролі зберігаються в хешованому вигляді (Werkzeug security)
- Сесії користувачів
- Перевірка прав доступу на рівні API
- Захист від дублікатів ICC кодів
## Підтримка
 
База даних зберігається у файлі `warehouse.db` в папці проекту. Для резервного копіювання просто скопіюйте цей файл.

- **Backend:** Python Flask
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Auth:** Flask sessions + Werkzeug password hashing
